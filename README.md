# 日文讀音 Quiz

Mobile-friendly Japanese vocab pronunciation quiz (hiragana / romaji).

Data from the Japanese Vocab Google Sheet · Vocab tab. Progress stored in `localStorage`.

## Play

Open `index.html` on your phone, or use the GitHub Pages URL once published.

## Rules

- See kanji → type reading (hiragana or romaji)
- 10 questions per round
- Simple score X/10
- Wrong / unseen words weighted to resurface
